Transformers provide strong language modeling, but attention prefill scales quadratically with context and KV-cache memory grows linearly, while efficient recurrent alternatives can trail in capability or underuse GPU decode hardware. We introduce Mamba-3, an inference-first state-space architecture that improves recurrence, state dynamics, and input-output structure together. Mamba-3 combines an exponential-trapezoidal recurrence with learned trap interpolation, complex-valued updates implemented as data-dependent rotations, and a rank-4 multi-input multi-output (MIMO) formulation designed to raise arithmetic intensity during memory-bound decoding. The resulting model preserves linear-time sequence processing with a fixed-size recurrent state. We pretrain models up to 1.5B parameters on 100B FineWeb-Edu tokens. At 1.5B, MIMO improves over SISO from 10.35 to 10.24 perplexity and from 56.4 to 57.6 average downstream accuracy; the strongest listed non-Mamba-3 average is 55.8. The complex-valued update also delivers substantial gains over Mamba-2 and ablated variants on formal state-tracking tasks. The same MIMO configuration retains lower BF16 H100 kernel latency than Mamba-2 at state size 128, requiring 0.179 rather than 0.203 ms per token. These controlled comparisons show that richer state-space dynamics and MIMO computation can improve sequence-model quality while preserving efficient recurrent decoding.
